Cum instaleziHow to install

  1. Apasă butonul de mai sus. Dacă Chrome afișează „Fișierul poate fi dăunător”, apasă „Descarcă oricum” – altfel descărcarea rămâne blocată.
  2. Deschide fișierul descărcat (din notificare sau din „Descărcări”).
  3. Dacă telefonul întreabă, permite instalarea din această sursă. Dacă apare Play Protect, apasă „Instalează oricum”.
  4. Deschide aplicația, alege-ți strada și permite notificările.
  1. Tap the button above. If Chrome says “File might be harmful”, tap “Download anyway” – otherwise the download stays stuck.
  2. Open the downloaded file (from the notification or “Downloads”).
  3. If your phone asks, allow installing from this source. If Play Protect appears, tap “Install anyway”.
  4. Open the app, choose your street and allow notifications.

Descărcarea nu se termină?Download won't finish?

  • Rămâne la 100%? Chrome așteaptă confirmarea: meniul ⋮ → Descărcări → la CalendarGunoi.apk apasă „Păstrează” / „Descarcă oricum”. Dacă scrie „Fișier periculos blocat”, încearcă din Samsung Internet sau Firefox.
  • Deschide pagina în Chrome, nu din Facebook, Messenger sau Instagram.
  • Dacă ai aplicația GitHub pe telefon, deschide linkul din Chrome (ține apăsat pe link → „Deschide în Chrome”).
  • Uită-te în bara de notificări: s-ar putea să aștepte confirmarea „Descarcă oricum”.
  • Verifică dacă ai măcar 100 MB liberi pe telefon.
  • Stuck at 100%? Chrome is waiting for confirmation: ⋮ menu → Downloads → next to CalendarGunoi.apk tap “Keep” / “Download anyway”. If it says “Dangerous file blocked”, try Samsung Internet or Firefox.
  • Open the page in Chrome, not inside Facebook, Messenger or Instagram.
  • If the GitHub app is installed, open the link in Chrome (long-press the link → “Open in Chrome”).
  • Check the notification bar: it may be waiting for “Download anyway”.
  • Make sure you have at least 100 MB free.

Ce faceWhat it does

  • Următoarea ridicare, cu numărătoare inversă, pentru strada ta
  • Toate ridicările: pubela neagră/maro, sac galben/verde, albastru, transparent
  • Mementouri (implicit 18:00 cu o zi înainte și 06:00), cu buton „Am scos-o”
  • Widget pe ecranul telefonului și export în Google Calendar
  • Română și engleză
  • Next pickup for your street, with a countdown
  • All pickups: black/brown bin, yellow/green, blue and clear bags
  • Reminders (18:00 the day before and 06:00 by default) with an “It's out” button
  • Home-screen widget and Google Calendar export
  • Romanian and English
